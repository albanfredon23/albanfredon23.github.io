AIOTECH · Spherical Constraint Graph

Élaguer avant de générer

Prune before generating

Les états candidats vivent sur une sphère unité. Chaque contrainte d'exploitation y découpe une calotte interdite. Une trajectoire n'est conservée que si son degré d'admissibilité, agrégé par la t-norme de Gödel, reste strictement positif. Les hallucinations sont éliminées géométriquement, avant le décodage.

Candidate states live on a unit sphere. Each operating constraint cuts a forbidden cap out of it. A trajectory is kept only if its admissibility degree, aggregated with the Gödel t-norm, stays strictly positive. Hallucinations are removed geometrically, before decoding.

AIOTECH · Green AI

Calculer seulement ce qui est nécessaire

Compute only what is needed

L'AdaptiveComputeGate arrête la propagation d'un token dès que sa confiance franchit le seuil de sortie. Les tokens faciles quittent le réseau tôt, les difficiles le traversent en entier. Avec une allocation k-dynamique du contexte RAG, le middleware réduit les FLOPs de 40 à 60 % (estimation) et allège l'empreinte VRAM.

The AdaptiveComputeGate stops a token's propagation as soon as its confidence crosses the exit threshold. Easy tokens leave the network early, hard ones go all the way through. Combined with k-dynamic allocation of the RAG context, the middleware cuts FLOPs by 40 to 60 % (estimate) and lowers the VRAM footprint.

AIO v3 · Résultat négatif

AIO v3 · Negative result

Quand les gradients s'effondrent

When gradients collapse

Dans AIO v3, la sélection des chemins de raisonnement passait par un masque dur (argmax). Le passage avant fonctionnait, mais l'argmax a une dérivée nulle presque partout : aucun gradient n'atteignait les couches amont, qui ont cessé d'apprendre. Le remplacement par Gumbel-Softmax avec estimateur Straight-Through garde une décision discrète à l'aller et transmet un gradient continu au retour.

In AIO v3, reasoning paths were selected with a hard mask (argmax). The forward pass worked, but argmax has a zero derivative almost everywhere: no gradient reached the upstream layers, and they stopped learning. Switching to Gumbel-Softmax with a Straight-Through estimator keeps a discrete decision on the forward pass and sends a continuous gradient on the backward pass.

y_soft = softmax((log π + g) / τ), g ~ Gumbel(0, 1) y = y_hard − sg(y_soft) + y_soft avant : y = y_hard arrière : ∂y/∂π = ∂y_soft/∂π

AIO-SecEng · SecOps & Bug Bounty

Masquer seulement ce qui est réellement sensible

Mask only what is actually sensitive

Le masquage PII valide chaque séquence numérique avec l'algorithme de Luhn avant de la caviarder : un vrai numéro de carte est masqué, un identifiant qui lui ressemble ne l'est pas. Même principe pour l'anti-injection : des invariants explicites plutôt que des listes noires.

PII masking validates each digit sequence with the Luhn algorithm before redacting it: a real card number is masked, an identifier that only looks like one is not. Same principle for injection protection: explicit invariants instead of blocklists.

def luhn_valid(digits: str) -> bool: total = 0 for i, ch in enumerate(reversed(digits)): d = int(ch) if i % 2 == 1: d = d * 2 - 9 if d > 4 else d * 2 total += d return total % 10 == 0
